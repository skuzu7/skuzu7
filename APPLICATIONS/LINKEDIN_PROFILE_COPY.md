## About — recommended English version

I work at the intersection of software engineering, application security and AI-agent security research. I focus on evidence-based findings: defined testing scope, reproducible local experiments, root-cause analysis, minimal patches and regression tests.

My public projects include:

**CSA-LAB:** six deliberately vulnerable first-party application scenarios (authorization, SQL injection, path traversal, session security, business logic and SSRF), with written root-cause analysis, patches, regression checks and reproducible CI workflows.

**TRACEGUARD:** offline research into AI-agent tool boundaries, using paired synthetic scenarios, a host-side authorization policy and inspectable test traces. The results are based on scripted controls, not live-model robustness measurements.

**Scoped Agent Evals:** evaluation methodology for prompt-injection-related agent action proposals, documented scenarios and offline tests, with explicit separation between synthetic baselines and future live-provider evaluations.

**freeband-nextjs:** first-party web application with STRIDE threat modeling, authentication/session review and documented dependency remediation.

I am interested in **authorized** web/API vulnerability research, secure software delivery and AI-agent security evaluations. I value precise evidence, human review, responsible disclosure and documenting the limits of every test.

My publicly verifiable work is primarily first-party and synthetic research. I do not represent it as externally credited CVEs, paid bug bounty findings, professional offensive certifications or customer engagements.

Portfolio and evidence: https://github.com/skuzu7/skuzu7/blob/main/SECURITY_PORTFOLIO.md
